# Оценка зрелости агентного управления

Методика: **4 области** (инфраструктура C1–C2, управление C3–C8, агенты C9, организация C10–C11) × **3 аспекта** (технология, ответственность, применение правил) × **4 уровня** (1 отсутствует … 4 действует).

## Правило

Оценка области = **минимум** трёх аспектов, не среднее. Уровень системы = минимум по областям. Предельный режим работы обычно задаёт самый слабый аспект в **управлении**.

## API

| Метод | Путь | Назначение |
|-------|------|------------|
| GET | `/api/maturity/matrix` | полная матрица описаний ячеек |
| GET | `/api/maturity` | текущие 12 оценок + профиль режима |
| PUT | `/api/maturity/scores` | обновить одну или несколько ячеек → snapshot |

## UI

Раздел **Зрелость** (`/app/maturity`): профиль режима, минимумы по областям, интерактивная матрица.

Seed «СеверПром» — иллюстративный профиль (инфраструктура выше, применение правил в управлении отстаёт).
